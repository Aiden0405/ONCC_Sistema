Gestión de Seguridad y Accesos (RBAC)

El sistema utiliza un Control de Acceso Basado en Roles (RBAC)[cite: 8]. Los privilegios son capacidades atómicas (ej: `crear_divulgaciones`) registradas en un catálogo global[cite: 8]. Desde el panel de Roles, un operador con permisos puede modificar las casillas para reconfigurar en tiempo real qué puede hacer cada cargo institucional[cite: 8].

Cualquier transacción de creación, edición o eliminación ejecuta de manera automatizada una traza inmutable en el módulo de auditoría del servidor[cite: 8]. Esto registra el operador, la acción, el ID del recurso y el detalle exacto de la modificación.

Sistema de Notificaciones y Alertas

Este es un comportamiento de persistencia deliberado para la seguridad del ecosistema. Desplegar la campanita remueve el indicador en la pantalla actual para comodidad visual, pero el estado del registro en PostgreSQL permanece marcado como "no leído". El indicador global solo se apagará de forma permanente una vez que el usuario visite formalmente el historial detallado de notificaciones, lo que garantiza el acuse de recibo de alertas del sistema.

Las notificaciones están categorizadas dinámicamente: las de color azul corresponden a flujos de "Usuarios", las grises a procesos de "Sistema" y las amarillas corresponden a alertas críticas de "Seguridad" (como variaciones de la matriz RBAC, eliminación de expedientes o boletines de divulgación climática de alta prioridad)[cite: 8].

Gobernanza de Divulgación y Boletines

Cuando un Técnico genera un reporte, se registra bajo el estado de "Borrador". El boletín se almacena de forma aislada y no es visible para la ciudadanía hasta que un Administrador o Superusuario valida los datos y ejecuta la acción transaccional "Aprobar y Publicar".

El campo de desarrollo utiliza formato Markdown estándar para estructurar la información sin comprometer la seguridad. Los botones de la barra superior permiten inyectar de manera automatizada las etiquetas para Negrita, Cursiva, Encabezados, Listas ordenadas y bloques de Citas para notas aclaratorias.

La prioridad determina el orden jerárquico de renderizado en el portal público principal. Adicionalmente, si una publicación se aprueba con una prioridad mayor o igual a 7 (ej: alertas críticas por lluvias o incendios), el sistema la procesa automáticamente bajo la categoría de "Seguridad", alertando de inmediato a todo el personal administrativo a través del panel de control.
